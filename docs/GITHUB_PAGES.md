# GitHub Pages

静态网站源码位于 `site/`，包含产品介绍、使用帮助和隐私政策。网站不依赖构建框架、分析脚本或第三方字体。

| 页面 | 地址 |
| --- | --- |
| 产品介绍 | https://xiaomao361.github.io/dockshelf/ |
| 支持与帮助 | https://xiaomao361.github.io/dockshelf/support/ |
| 隐私政策 | https://xiaomao361.github.io/dockshelf/privacy/ |

Pages 使用 `codex/github-pages` 分支根目录发布。该分支只包含 `site/` 的公开文件，不包含应用源码、内部记录、原始用户截图或分发日志。

更新流程：修改 `site/`，检查站内链接、可访问文本、版本状态及隐私内容，将网站树提交到网站分支，推送后检查 Pages 构建结果和在线资源。发布必须基于远端现有网站提交继续推进，不能强制覆盖其他更改。

隐私正文以根目录 `PRIVACY.md` 为准，网站变更应同时核对该文档。GitHub Pages 的运行与访问数据处理由 GitHub 的服务政策约束。
