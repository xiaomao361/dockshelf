# 搁这儿 v0.1.4

拖起文件或文件夹时，搁板会自动在菜单栏图标下方展开，移入松手即可暂存引用。成功放入后约 0.35 秒开始收起，鼠标停留不会取消收起。

## 更新

- 自动展开默认开启，可从菜单栏右键菜单关闭；Control–Option–空格也可显示搁板。
- 面板和菜单栏统一使用原生 AppKit 文件拖放接收路径，改进文件与文件夹导入。
- 区分部分加入、重复、不可访问和容量不足，保留替换撤销。
- 调整文件卡片、路径提示、Finder 入口、反馈区和列表滚动，减少不可见时刷新。
- 清除全部引用增加确认；原文件始终不会被移动、复制或删除。

## 安装与范围

Apple Silicon（arm64），macOS 14 或更高版本。下载 DMG 后退出旧版，将“搁这儿”拖入“应用程序”替换即可。无自动更新。

## 验证边界

Release 构建、模型与原生拖放冒烟、自动拖拽检测及独立收起计时回归通过。用户已确认本轮方向并授权发布；自动化检查不代表所有 macOS 版本、第三方拖拽来源或长期使用均已验收。异常/部分加入和替换结果仍保留可操作反馈。
