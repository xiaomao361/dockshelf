# macOS 原生实现与验收记录

更新日期：2026-08-11（Asia/Shanghai）

## 当前结论

原生技术路线成立，核心产品流程已经打通。用户在本轮真实操作后确认整体功能和效果可用；项目可以从“技术探针”进入“候选构建验收与本地打包”阶段。

当前最远验证层是：**Debug/Release 构建 + 本地运行 + 用户对核心交互的主观验收**。尚未完成签名、公证、安装包、外部应用完整矩阵或长期自用验收。

## 已实现

- `LSUIElement=true`，没有 Dock 图标和普通主窗口；
- `NSStatusItem` 菜单栏入口与自绘 Template Icon；
- 点击显示或收起临时 `NSPanel`；
- 有内容时悬停菜单栏图标 300 ms 自动展开；
- 面板关闭时把文件或文件夹拖到菜单栏图标会立即展开接收界面，并保持 Finder 拖拽会话；
- 拖入成功后显示短反馈并自动收起；
- 从搁板向外拖出时保持面板，拖拽结束后自动收起；
- 从搁板拖回自身时拒绝该操作，避免系统为文件夹生成临时副本后形成重复引用；
- 手动打开时支持点击外部或 Esc 收起；
- 右键菜单提供显示、清空临时文件、清空全部引用和退出；
- 只接收现存的本地文件和文件夹；
- 拒绝结果保留明确提示和“返回”操作，状态栏图标在面板可见时可直接关闭；
- 同一标准化路径去重，搁板最多保存 20 个引用；
- 文件可固定或取消固定，固定引用会在退出并重启应用后恢复，普通引用仍只保留在当前会话；
- 容量不足时自动替换最早加入的未固定文件，固定文件不参与自动替换；
- 自动替换后保留一次可撤销的完整快照，撤销会恢复替换前的文件与排列顺序；
- 未固定文件不足时整批拒绝，不会部分加入或覆盖固定文件；
- 显示 macOS 系统文件或文件夹图标、名称和失效状态；
- 固定、移除和清空只改变引用记录，不操作原文件；
- 横向文件列表支持触控板横向滚动，并把鼠标纵向滚轮映射为横向滚动；
- 文件卡片具备悬停抬升、移除按钮和向外拖出能力；
- 支持减少动态效果设置；
- macOS 26 使用 `NSGlassEffectView`，旧系统降级为 `NSVisualEffectView`；
- 面板使用系统颜色、系统字体和系统文件图标，不再使用固定暖黄主题；
- 菜单栏图标在面板打开期间使用持续选中状态；
- 面板优先让图标靠近左上，右侧空间不足时切换到右上，并与菜单栏保留 12 pt 计算间距；
- 进出场使用克制的淡入淡出与轻微位移。

## 本轮已验证

- Xcode 26.6 可识别 `DockShelf` target 和 shared scheme；
- Debug 构建成功；
- Release 构建成功；
- 应用进程能够稳定启动；
- 构建产物 `Info.plist` 中 `LSUIElement=true`；
- 菜单栏状态项、临时面板和原生玻璃材质完成真实渲染；
- 用户确认核心流程、交互和最终视觉效果可用。

## 仍需正式验收

以下项目不能从“整体功能可用”自动推导为已通过：

- 针对同一候选构建记录 Finder 单文件、多文件与文件夹拖入结果；
- 固定、重启恢复、容量替换、全固定拒绝和撤销的完整人工确认；
- 拖回 Finder、拖入浏览器上传区、拖入真实聊天或邮件应用；
- 中文、空格、特殊字符和超长路径；
- 源文件删除后的失效状态；
- 20 项时鼠标滚轮和触控板滚动的最终人工确认；
- 浅色、深色、降低透明度和减少动态效果；
- 多显示器、不同菜单栏位置和全屏空间；
- 空闲内存、CPU、启动时间和应用体积；
- 本地安装、签名、公证和 Gatekeeper。

## 阶段边界

原生 M0 不再是技术阻塞项。下一步先对一个固定候选构建完成精简验收矩阵，再决定是否制作可长期自用的签名应用；不要在此之前重新扩展搜索、持久化、快捷键、Windows 或其他产品范围。
