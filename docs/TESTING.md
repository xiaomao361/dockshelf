# 测试与交互验证

## 自动回归

`bash scripts/validate.sh` 执行：

| 检查 | 范围 |
| --- | --- |
| Store | 去重、顺序、容量、固定保护与撤销 |
| Interaction | 接收、取消、部分完成、恢复与拖出状态 |
| Refinement | 原生 URL、文件夹、失败计数、会话计时及源文件完整性 |
| Recovery | 迁移、备份、授权恢复、损坏记录与保存失败 |
| Shortcut | 录入、保留键、冲突、注册回滚和设置保存 |
| DropTarget | 空白区域命中、接收祖先、边界及自身回投规则 |

组件检查 `ShelfAppearanceSmoke.swift` 覆盖底部操作区间距、悬停任务取消、键盘焦点与类型图标，并生成深浅外观和接收态的离屏图。

## 手动交互检查

1. 从 Finder 拖入单个、多个文件和文件夹，分别放到台面空白处、文件间隙及两端。
2. 连续快速拖入，验证旧会话不关闭新会话；分别拖到 Finder、浏览器上传框等目标。
3. 悬停后拿起，检查影像衔接；按 Esc 取消，确认原引用保留。
4. 使用 1、5、6 和 20 项检查居中、横向滚动、翻页及固定/移除命中；检查长中文名和同名文件。
5. 测试容量替换、全固定拒绝、重复/失败混合、撤销及取消后恢复原反馈。
6. 固定后重启；导入备份，验证部分失效、文件夹批量恢复、路径移动及外置卷断开。
7. 检查键盘导航、VoiceOver、减少动态效果、减少透明度、深浅外观、多显示器和屏幕边缘。

自动测试和离屏图不能证明跨应用事件投递、WindowServer 命中或所有系统外观正确。提交问题时应注明版本、场景和复现步骤，隐藏私人文件名、路径与书签。
