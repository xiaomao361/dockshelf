# 架构与数据模型

## 应用层次

| 组件 | 职责 |
| --- | --- |
| `AppDelegate` / `StatusBarController` | 菜单栏、生命周期、偏好与命令入口 |
| `ShelfPanelController` | 浮动面板锚点、会话、展开与收起时序 |
| `ShelfView` / `DockShelfTheme` | SwiftUI 文件展示、悬停、材质与拖拽影像 |
| `ShelfImport` / `ShelfHostingView` | AppKit 文件粘贴板读取及整区域接收 |
| `ShelfDragMonitor` | 识别新的外部文件拖拽，不读取通用剪贴板 |
| `ShelfInteractionState` | 接收、处理、成功、重复、部分失败、撤销与拖出状态 |
| `ShelfStore` | 引用顺序、去重、容量、固定及串行导入 |
| `ShelfFileAccess` / `ShelfPersistence` | 安全作用域租期、书签、持久化与恢复 |
| `ShelfShortcut` / `ShelfHelpWindow` | 快捷键录入、冲突处理、帮助与关于 |

## 文件引用

搁板存储原文件的路径引用，不持有文件内容副本。原生拖出使用文件 URL 和应用来源标记；回投到搁板自身会被拒绝。目标应用决定后续复制、上传或发送行为。

引用按原路径去重，最多 20 项。固定项受容量替换保护；新增超过容量时替换最早临时项。替换提供一次可撤销快照。固定、移除等后续修改会使旧撤销快照失效，避免覆盖较新的状态。

## 权限与持久化

商店配置仅申请 App Sandbox、用户选择文件只读访问和应用作用域书签。安全作用域租期覆盖导入检查、显示及拖出，引用和撤销快照共同持有租期。

临时引用仅在内存中保存。固定记录和偏好通过 UserDefaults 存储；格式迁移保留旧记录及恢复副本。备份包含已有访问书签，恢复时仍由系统验证，不将路径字符串视为授权。

批量恢复只处理已经记录的原路径，不枚举或导入所选文件夹中的其他文件。路径移动、失效书签、拒绝访问、部分恢复及保存失败分别保留状态。文件移动后不自动跟随新路径。

## 交互与绘制

面板锚定菜单栏图标。每个新拖拽替换旧会话并取消旧的关闭任务；原生拖拽 session 回调决定拖出结束，取消不视为成功。悬停名称采用可取消的短延迟，键盘焦点立即显示。

图像与原生命中层共用抬起位移，接触阴影留在承托面。绘制与原生拖拽影像复用文件组件。内容预览使用系统 Quick Look；预览不可用时保留类型图标，文件可用性独立判断。减少动态效果时关闭位移与翻折。
