# 搁这儿 v0.1.5

版本：0.1.5（2026101901）  
日期：2026-10-19（Asia/Shanghai）  
状态：正式 App/DMG 已完成 Developer ID 签名与 Apple 公证，GitHub 发布准备中。见 [发布回执](RELEASE_v0.1.5.md)。

## 交互修复

- 取消新一次拖入后恢复之前的替换、部分完成或错误反馈，撤销入口继续可用。
- 自动展开后，经过菜单栏图标再移开不会因状态栏拖离计时提前收起；成功放入仍约 0.35 秒后开始收起。
- 拖出经过 15 秒但鼠标仍按住时继续等待，不提前结束面板会话。
- 右键菜单合并为一个“显示／收起搁板”，使用原生菜单快捷键展示。

## 界面与反馈

- 悬停或聚焦卡片时，空闲底栏显示文件名称及所在目录；反馈占用底栏时，顶部继续显示该文件名称。长文字仍可能截断，完整路径可通过悬停提示查看。
- 固定与移除按钮移至卡片下方，与上部图标拖动区域分开；固定状态仍有持续标记。
- 超过五项时提供左右翻动按钮，保留原有鼠标及触控板滚动。
- 拖入时保留容量，并预告满容量下的可能替换或固定位置不足；不会在悬停中读取路径或猜测准确替换数量。
- 部分失败或全失败可查看详情；已知失效路径与无法识别身份的项目分别展示。详情仅在本机内存保存，日志仍只有计数。
- 成功反馈显示加入数量；完成、失败、替换与撤销结果发出辅助播报请求。
- 新增卡片使用轻微向下落位和淡入，移除使用淡出与列表让位；减少动态效果时取消位移和滚动动画。

## 保持的产品规则

420 × 146 pt 原生菜单栏浮层、系统图标和材质、20 项上限、原位置文件引用、路径去重、固定项跨重启保留、最早临时项替换及一次完整替换撤销均保持。没有新增网络、账号、云同步、剪贴板历史或内容复制。

## 验证与验收

自动化验证与候选构建回执见 [优化计划](OPTIMIZATION_2026-10-19.md)。真实拖放、长文件名辨认、操作命中、翻动、深浅色、减少动态效果及 VoiceOver 仍待用户人工验收。构建和隔离测试不代表这些体验已经通过。

系统范围保持 Apple Silicon（arm64）、macOS 14+。正式公证安装包位于 `.build/releases/v0.1.5/`；早先本地未公证测试包独立保留，历史记录见 [打包回执](PACKAGE_v0.1.5.md)。
