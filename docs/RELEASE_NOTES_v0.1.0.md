# 搁这儿 v0.1.0

首个公开版本。

## 下载范围

- Apple Silicon Mac（arm64）
- macOS 14 Sonoma 或更高版本
- Developer ID 签名、Apple 公证的 DMG

## 核心能力

- 从 Finder 向菜单栏图标或搁板拖入文件和文件夹；
- 从搁板向 Finder、浏览器、聊天或邮件应用拖出；
- 最多 20 项，同一路径去重；
- 固定项跨应用重启保留，普通项退出后清空；
- 容量不足时替换最早的未固定项，并支持一次撤销；
- 原文件失效状态、浅色/深色外观、减少动态效果和多空间浮动面板；
- 不复制、移动、上传或修改原文件。

## 已知边界

- 仅支持 Apple Silicon，不支持 Intel Mac；
- 不提供自动更新，请从 GitHub Releases 手动下载新版；
- 不提供开机自动启动；
- 原文件被移动或删除后不会自动追踪新位置；
- 普通项目退出应用后清空属于产品设计；
- 当前不通过 Mac App Store 分发。

## 安装

打开 DMG，将“搁这儿”拖入“应用程序”，再从“应用程序”启动。启动后应用只显示在菜单栏，不显示 Dock 图标。
