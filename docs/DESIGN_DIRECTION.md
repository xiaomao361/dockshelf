# 搁这儿 · macOS 视觉方向

更新日期：2026-10-19（Asia/Shanghai）

## v0.1.5 本地优化候选

在下述生产方向上局部优化，不重做品牌或扩大面板：

- 68 × 84 pt 卡片保留 42 pt 图标；悬停/聚焦时，名称区域切换为底部两个 28 pt 管理按钮，图标与按钮热区分开。固定状态为非交互小图钉，失效标记置于另一侧。
- 没有操作结果反馈时，底栏显示悬停/聚焦项目的名称和目录；反馈占用底栏时，将当前检查项目的名称保留在顶部。没有检查项目时显示拖动/滚动提示。超过五项增加左右翻动按钮。
- 拖入时仍显示容量，已满时提示可能替换较早临时引用或需要腾出固定位置。只依当前搁板状态提示，不读取悬停文件路径，也不猜测去重后的精确结果。
- 反馈优先于普通底栏。实际无法读取项目可通过信息按钮展开本地详情，未知身份不映射为其他文件名。
- 新卡片 140 ms 淡入并向下落位 4 pt，移除淡出并让位；沿用面板 160/110 ms 和悬停 120 ms。减少动态效果时取消位移和翻动动画。
- 成功显示加入数量并请求辅助播报；仍保持 350 ms 开始收起，替换/部分失败/拒绝保留可操作反馈。

当前是源码和构建候选，真实尺寸、深浅色、复杂壁纸、命中区、滚动、VoiceOver 与减少动态效果尚待用户验收。以下已确认规则及历史人工结论仅作为基线，不直接证明本候选通过。

## 最终生产方向

Figma 探索阶段曾选择 “B · Physical Ledge 为主、A · Native Precision 为辅”。经过真实运行和多轮人工比较，生产实现进一步收敛为：**保留搁板语义与品牌图标，界面表现遵循 macOS 原生菜单和小组件。**

最终版本不再使用固定暖白面板、黄色承托边或 Figma 自定义文件类型图标。背景颜色来自桌面和系统材质，文件类型直接使用 macOS 系统图标。

## 已确认的视觉规则

- 面板是临时系统浮层，不是大号桌面窗口；固定尺寸为 420 × 146 pt。
- macOS 26 使用原生 `NSGlassEffectView` 毛玻璃，macOS 14–15 使用 `NSVisualEffectView` 降级。
- 颜色使用系统语义色：强调色、分隔色、控件背景色和错误色；不维护独立品牌配色主题。
- 字体使用 SF 系统字阶，不导入产品字体。
- 文件图标来自 `NSWorkspace`，保留系统熟悉度与文件类型覆盖。
- 菜单栏图标、App icon 和 Logo 使用同一套“一张卡片刚刚落在搁板上”的 A2 视觉骨架。
- 菜单栏保持单色 Template Icon；App icon 使用矿物青、乳白、石墨与接触点琥珀色；Logo 以中文“搁这儿”为主标。
- 面板打开时，菜单栏图标显示系统原生的半透明选中反馈。
- 宽面板不与菜单栏图标强制居中：优先靠近面板左上，右侧空间不足时靠近右上。
- 面板与菜单栏留出可见但克制的间距；当前计算间距为 12 pt，用来抵消窗口阴影造成的视觉贴合。
- 面板外框只保留低对比度结构线和系统阴影，不添加装饰性横线。
- 文件卡片悬停或键盘聚焦只增强背景与边框，120 ms ease-out；不再抬升、缩放或改变阴影。
- 面板进入为 160 ms 淡入并下落到位，退出为 110 ms 淡出和微位移；遵循“减少动态效果”。

## 交互状态

- Empty：放大的系统图标、16 pt 主文案“把文件或文件夹先搁这儿”、13 pt 副文案“原文件不会移动，需要时再拖出去”。
- Drop Valid：使用系统强调色显示“松手放到搁板”。
- Drop Invalid：使用系统错误色显示“这里只接受文件或文件夹”。
- Success：以克制的向下落位过渡显示“已搁好”约 0.35 秒，随后自动收起；减少动态效果开启时不执行位移动画。
- Exporting：显示“拖到需要的位置”，拖拽结束后收起。
- File Hover / Keyboard Focus：增强背景和边框，显示 28 pt 命中区的固定与移除引用按钮；文件名使用 caption 字阶、两行中间截断，悬停可看完整路径；右键可在 Finder 中显示。
- Missing Reference：降低文件图标与文字强度，显示不覆盖移除按钮的红点并禁止拖出；悬停提示原文件已移动、删除或暂不可访问，并提供原路径。
- Capacity：右上角显示 `当前数量/20`；列表支持滚动条，超过五项显示左右滚动提示，新增项目自动进入视野。
- Pinned：文件卡片悬停时可固定；固定项持续显示小图钉，并在应用重启后恢复。
- Replacement：容量不足时替换最早的未固定文件，显示替换数量与“撤销”；固定项不足以腾出空间时给出明确恢复建议。
- Removal：菜单统一使用“移除引用”术语；无可移除项目时禁用对应项，移除全部引用前明确确认不会删除原文件。

## Figma 资产的保留边界

Figma 文件保留探索过程、状态覆盖、组件思路和菜单栏图标资产，作为设计历史与后续讨论入口，不再作为像素级生产真相。

- 保留：Brief、References、Directions、Recommended、States、Components & Assets。
- 继续使用：A2 单卡片落在搁板上的单色 SVG，以及 `docs/brand/` 中的同源品牌资产。
- 不直接实现：暖白 surface、黄色 ledge、定制文件类型图标、双列 Dense 20 版式。
- 系统功能图标继续使用 SF Symbols，不导出品牌资产。
- Figma 文件未发布为 Library，`File Reference Item` 也未建立远程 Code Connect。

## 2026-09-15 精修候选

保持 420 × 146 pt；顶部 24 pt 容量区、84 pt 文件卡片、底部 38 pt 反馈区。文件图标为 42 pt，反馈固定在底部，避免遮挡文件名。部分导入结果显示加入、替换、重复及无法读取数量，保留“返回”和可用时的“撤销”；完整成功仍短暂反馈后收起。

这些是本轮实现决策，真实小尺寸、深浅色、滚动、焦点和拖放效果尚待用户验收，不继承旧版人工通过结论。

## 2026-08-11 人工结论

用户在本轮最终确认当前原生玻璃、系统色、文件卡片、锚点和间距的整体效果良好。后续视觉修改应以真实摩擦为依据，避免重新引入统一暖色主题或扩大面板体量。
