隐私政策

文件保留在原处，搁板记录保存在本机。下面说明应用和支持网站如何处理信息。

更新日期：2026-10-30

本说明适用于 Mac App Store 版本的文件引用、固定记录备份与访问恢复。不同分发版本的可用功能以安装版本为准。

“搁这儿”是一款在本机运行的 macOS 菜单栏文件搁板。

应用处理的信息

  • 你主动拖入的本地文件或文件夹引用，以及主动选择导入的固定记录；
  • 固定项目的绝对路径、加入时间和用于重启访问的只读安全作用域书签；
  • macOS 提供的文件图标、本地内容缩略图和当前位置的可访问状态；
  • 自动展开开关等本机偏好。

临时引用仅保留在当前进程内。固定引用、书签和偏好通过应用自己的 UserDefaults 保存。为避免迁移、读取失败或恢复操作造成引用丢失，旧记录、上一次有效记录和主动导入的记录会保留恢复副本；恢复损坏记录前，还会将被替换的原始记录保存在应用自己的恢复目录中。

路径可能包含用户名、目录名或文件名；书签包含文件位置与访问授权信息。这些都应当视为本地敏感信息。不要将偏好导出、书签或恢复副本公开分享。

自动展开与快捷键

开启“拖动文件时自动展开”时，应用观察鼠标左键按下和松开，仅在按住期间检查拖拽粘贴板的变更序号、文件类型和本应用来源标记。识别阶段不读取文件路径或内容，不读取通用剪贴板，不保存鼠标轨迹，也不记录任意键盘输入。只有实际放入搁板时才读取文件引用。关闭此开关会停止相应观察和检查。

默认快捷键为 Control–Option–空格，可在“帮助与关于…”中修改。应用只注册你选择的一个明确组合，键码与组合修饰键及显示名保存到本机偏好。仅在你点击修改后，在该帮助窗口内接收用于录入的按键；取消、关闭或离开窗口即结束，不建立全局普通键盘监听，也不记录其他应用的键入。注册前读取系统已启用快捷键以避免冲突，不上传这些设置。应用使用本机单调时钟计算识别间隔与计时，不将这些信息发送到设备外。

文件访问与拖出

应用只保存引用，不主动复制、移动、删除、修改或上传原文件。固定书签用于恢复你已授予的只读访问。导入备份会尝试解析并验证已有访问书签，不会把一条路径或未验证的书签视为已授权。旧版路径记录或失效授权，可选择所在文件夹一次恢复其中已记录的多个项目，或单独选择原文件。选择文件夹由系统授予只读访问，应用只检查已记录的路径，不枚举或加入其他文件；链接指向所选文件夹外时不自动恢复。

文件换了位置时，应用不会静默改用书签跟随到的新路径；请移除旧引用，再从新位置拖入。外置卷或云盘暂不可用时，不将其断言为永久删除。

你将项目拖给 Finder、浏览器或其他应用后，目标应用可能按你的操作复制、上传或发送文件；该阶段由目标应用处理，适用目标应用的隐私政策。

照片与 PDF 可通过系统 Quick Look 生成本地内容缩略图，用于搁板展示。应用不将这些缩略图或原文件上传到开发者服务。预览不可用时仍可使用类型图标。

导入与导出固定记录

“导出固定记录”生成恢复备份，包含当前固定引用的路径、排列顺序、加入时间和已有的应用作用域访问书签，不包含临时引用或原文件内容。暂不可用的固定引用仍保留；未保存的固定更改可导出并明确提示。

备份写入应用自己的本机导出目录，生成时设为仅文件拥有者可读写（0600）。成功后可主动选择在Finder中显示或复制路径，再自行保管。备份含私人路径和授权信息，不应公开分享；应用不主动上传或分享，也不因此取得原文件写入权限。

导入时由系统验证每个书签并尝试恢复访问，不能恢复的项仍保留并明确提示。书签主要用于同一Mac、同一用户、同一应用恢复，不保证跨机器、用户、签名变化后仍有效。仅含路径的旧记录继续支持；选择所在文件夹可批量恢复其中所有已记录项目，无需逐个重选源文件。

已有固定引用保留当前顺序和加入时间；新备份可修复其待恢复的访问权限，不覆盖工作正常的授权。与现有临时项冲突仍需先处理。导出的备份与本机恢复副本继续保留，应用不自动清理。

诊断与外部服务

应用没有账号、遥测、崩溃上报、广告跟踪、后台网络请求或云同步，也没有第三方运行时 SDK。诊断消息不包含你拖入文件的名称、路径、书签或内容。导入失败详情仅在当前会话内显示，不保存到诊断或偏好中。

在“帮助与关于”窗口选择“反馈问题”会通过系统默认浏览器打开 GitHub Issues；是否登录、发布及附带哪些信息由你决定。请勿公开包含私人路径、文件名或文件内容的截图与日志。

移除引用与保留的副本

点击项目的叉号或菜单中的“移除全部引用”会移除当前搁板的引用，不会删除原文件。上述恢复副本会继续留在本机，因此移除当前引用不等于抹除所有历史记录。应用不在后台删除这些副本。卸载应用也不应被理解为系统已经删除应用偏好与恢复目录。

隐私与清理本地记录的问题可发送邮件至 zhouwei@linux.com，或通过 GitHub Issues 联系开发者；无需附带真实文件记录。

支持联系与本网站

如果你主动发送支持邮件或提交公开问题，开发者会收到你主动提供的联系信息、问题描述和附件，用于答复与处理该问题。请勿附带原文件、访问书签、固定记录备份或包含私人路径的截图。公开问题中的信息会被其他人看到；相关邮件与网站服务按各自的隐私政策处理你提交的信息。

本网站使用 GitHub Pages 托管，没有接入广告或分析脚本，不设置分析或广告 Cookie。访问网站、打开 GitHub 链接时，GitHub 可能按照其隐私声明处理连接和访问信息。这与应用本身不发送文件记录或使用数据是不同的处理场景。

政策更新

如果未来版本改变数据处理方式，会在相关功能上线前更新本政策与商店隐私信息。隐私问题可通过上述邮箱联系 Zhou Wei。
